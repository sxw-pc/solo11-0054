# 合规声明

## 离线运行声明
SensorAlign 的运行期完全离线：

- 所有输入来自仓库内的本地 fixture 或用户明确指定的本地路径。
- 不发起 HTTP、DNS、套接字、消息队列或任何远程过程调用。
- 不包含遥测、自动更新、崩溃上报或外部服务回调。
- 测试 `test_no_network_modules_are_imported` 会扫描包内所有 Python 文件的
  import，禁止 `socket`、`urllib`、`http`、`requests` 等网络模块进入运行路径。
- 依赖仅 `PyYAML` 与测试用 `pytest`，均需预先离线安装。

## 合成数据声明
仓库内 `fixtures/` 下的全部测点、锚点、设备标识和时间戳均为人工合成的测试数据：

- 设备名统一为 `dev-a1`、`dev-b2`、`dev-c3`、`dev-d4`、`dev-e5` 等合成标识。
- 数值为简单的合成温度曲线，不对应任何真实设备、工艺或现场。
- 锚点事件为构造的公共事件，不对应真实采集记录。
- 不包含姓名、联系方式、密钥、令牌、真实地址、真实域名、真实公司名、
  真实设备型号或任何可识别个人/组织的信息。
- 示例中的 epoch 微秒值仅用于让时钟偏移、漂移和缺口计算可验证。

## 使用约束
本工具仅可用于：

- 本人拥有或已获得书面授权的数据；
- 经过脱敏、且授权范围覆盖对齐与分析用途的数据；
- 教学、科研、测试环境中的合成数据或公开授权数据；
- 在明确授权范围内的安全评估和数据质量核验。

使用者必须确保：**仅用于本人拥有或已获书面授权的数据**。不得将本工具用于
未获授权的数据采集、监听、抓取、拼接、去匿名化或绕过访问控制。

## 禁止用途
- 不得接入或采集未授权设备、网络、账号、设施或第三方系统。
- 不得把本工具改造成隐蔽采集器、远程控制通道或数据外传组件。
- 不得移除输出中的输入指纹与溯源信息后冒充原始数据。
- 不得把合成 fixture 描述为真实现场数据或用于误导性结论。

## 数据最小化与审计
- 工具只读取契约显式声明的本地文件，不扫描无关目录。
- 每个输入文件计算 SHA-256 指纹并写入台账，便于核对来源与变更。
- 每个输出格在 `aligned` 表中保留 `grid_index`、`ts_us`、`value`、`marker`，
  不做静默填充。
- `run` 表只保存确定性的运行 id 与契约/结果内容哈希，不保存运行时间戳，
  以支持可复现比对。
- 报告只显示相对路径和合成/用户提供的标识；不会写入密钥或环境变量。

## 责任边界
本工具提供时间基准对齐与质量指标，不保证输入数据本身真实、合法或满足特定
行业标准。使用者在导入任何数据前，应自行确认授权、隐私、出口管制、行业监管
和保留期限要求，并对最终分析结论负责。
